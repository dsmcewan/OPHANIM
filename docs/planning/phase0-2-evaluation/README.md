## Reusable evaluation checklist
For every item, record the objective, downstream consumer, contract, existing capability, exact source/evidence, alternatives, dependencies, missing information, independent acceptance, authority and stopping conditions. The JSON contains those fields for each of the twelve items.

**Necessity and structure:** require unique output ownership, existing acyclic dependencies and explicit scope/handoffs. A mandatory governance or acceptance requirement remains a blocker when missing, even if it is expensive. A source implementation or model name alone does not establish sufficient capability, reliability or expertise.

**Value of learning:** for a discretionary investigation, require competing predictions and an available method that measures a difference. Compare retained observations, instrumentation, paired replay and controlled ablation using the existing selector. Its value is:

`applicable workload × avoidable decision loss × chance of changing the decision × confidence × discrimination coverage − investigation, rollout, regression and opportunity costs`

Expected candidate gains remain separate. Missing inputs stay unknown, never measured zero. Retain `insufficient_evidence` when value or discrimination cannot be established and `no_change` when value is nonpositive or an applicable earlier decision suppresses repetition. This packet supplies no invented economics and invokes no selector on fabricated roadmap trace identities.

**Authority and eligibility:** a proposed investigation does not authorize execution. Preserve independent plan validation, plan registration, candidate verification, signed release decision and activation as separate steps. Existing software ceilings and fixture keys do not authorize accounts, provider spend or production effects.

The selector's material-change rules require applicable changed evidence/method/economics; a new timestamp or another phase is insufficient. Do not restart the signed-source optimization from this packet. Optional model advice remains subordinate to the deterministic result and requires its own authorized bounded route; this evaluation uses none.
